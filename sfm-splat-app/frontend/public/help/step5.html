5
Export PLY

Purpose

Optimise and re-export the raw .ply from Step 4 using SuperSplat — a web-based Gaussian Splat editor. This step removes outliers, reorders splats for faster streaming, and optionally compresses the output.

Export options

OptionDescription
Compress (SPLAT) Export as .splat binary — ~4× smaller than raw PLY
Keep raw PLY Also keep the original point_cloud.ply
Remove outliers Filter Gaussians with low opacity or extreme scale

How to use

  1. Review the preview in the PLY Viewer panel (bottom of the center area).
  2. Configure export options.
  3. Click Run Step 5.
The .splat format is recommended for web deployment (PlayCanvas, Three.js).

Output

Exported files saved to projects/<name>/export/.

Troubleshooting

  • SuperSplat not responding — The PLY file may be corrupt; re-run Step 4.
  • File too large — Enable compression or reduce iterations in Step 4.
  • Artefacts in export — Enable "Remove outliers" option.
