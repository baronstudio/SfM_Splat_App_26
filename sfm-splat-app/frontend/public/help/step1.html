Import Video / Images

Purpose

Copy or link your source media (video file or image folder) into the project's input/ directory so subsequent steps can access it.

Supported inputs

TypeFormats
Video .mp4, .mov, .avi, .mkv
Images .jpg, .jpeg, .png, .tiff

How to use

  1. Select Video file or Image folder using the file picker.
  2. The app copies the file(s) into projects/<name>/input/.
  3. Click Run Step 1 to confirm the import and advance.
For best results, capture footage with overlapping views ≥ 60 % and avoid motion blur.
Very large files (> 4 GB) may take a moment to copy — do not close the app.

Output

Files are stored in input/ under the project folder. Video is kept as-is; image sets are copied directly.

Troubleshooting

  • File not copied — Check disk space and file permissions.
  • Unsupported format — Convert to MP4/H.264 before importing.
