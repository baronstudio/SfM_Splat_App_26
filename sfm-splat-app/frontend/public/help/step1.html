Sources

Purpose

Put the source media into the project's input/ directory. Everything downstream reads from there, and no reset ever deletes it — a reset of any step leaves input/ alone, so re-extracting is always possible.

Two kinds of source

KindAcceptedWhat step 2 does with it
Video .mp4, .mov (plus .srt alongside) Extracts frames at a working fps
Image set .jpg, .jpeg, .png, .tif, .tiff Conforms them — every image becomes a frame

Importing a video

Drop it on the upload zone, or click it to browse. The file is uploaded into input/ with a live percentage. The list above the zone shows what is already there, with its size and a bin icon to remove it.

If input/ holds more than one video, step 2 badges the one the extraction will actually consume — the same function does the badging and the opening, so the badge cannot lie.

Importing an image set — three doors

They differ by cost, not by result:

DoorWhen to use it
Folder path The fast one. Type or paste a path on this machine and it is read server-side — a 20 GB set is a local copy, never an upload
Zip One upload, one unpack. Right for a set that arrived from somewhere else
File selection Drop the images, or use the browser's folder picker. The slow lane by construction — kept because it is the only one that works from another machine on the network

What happens to an imported set

  • The images are renamed to input/<set>/<set>_0001.png — zero-padded and contiguous, which is what lets FFmpeg read the whole set as one input instead of one subprocess per image.
  • imageset.json keeps the mapping back to the original filenames.
  • Several sets can live side by side; each is listed with its image count and origin, and can be removed on its own.
PNG with a real alpha channel is worth keeping. Step 2 offers to extract that channel into masks/, one greyscale PNG per frame — which is exactly the layout both the SfM and the training step read, with no further work.

Capture advice

  • Overlapping viewpoints, moving slowly and steadily — the curation gate in step 2 wants 2–12 % of frame width between kept frames.
  • Avoid motion blur; the sharpness pass will drop blurred frames, and dropping too many leaves gaps.
  • 360° and fisheye footage is a first-class input. Spirula reads equirectangular and >180° fisheye natively — there is no undistortion pass anywhere in this pipeline. Name the lens in step 3.

Output

projects/<slug>/input/ — the video as it was uploaded, or one subdirectory per image set.

Troubleshooting

  • Nothing lands — check disk space and that the path you typed exists on the machine running the app, not on the machine running the browser.
  • An unusual video container — the extraction opens it with FFmpeg, so most things work; if it does not, convert to MP4/H.264 first.
  • A set that is not a clean sequence — it still imports, file by file, and says so in the log; it is only slower.
