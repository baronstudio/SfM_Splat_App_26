Reality Capture — Alignment & Export

Purpose

Run Reality Capture (RealityCapture) in headless / command-line mode to align cameras, reconstruct a sparse point cloud, and export the result (camera poses + colmap-compatible data) into rc_output/.

What RC does automatically

  1. Detects feature points across all frames.
  2. Matches features between overlapping images.
  3. Estimates camera poses (SfM — Structure from Motion).
  4. Exports camera parameters and sparse point cloud.

Prerequisites

  • Reality Capture executable path set in Settings.
  • At least 80 frames with ≥ 60 % overlap recommended.
  • Nothing to prepare on the script side: the .rscmd is generated for each run from your settings and written to rc_output/align.rscmd, so you can read exactly what RC was asked to do.
RC works best with evenly distributed viewpoints. Walk around the object slowly in overlapping circles.
Sequences are not separate RC projects. Every frame of every sequence goes through one alignment; the goal is a single component. If alignment splits, the frames outside the largest component are dropped from the export — the Alignment coverage panel shown after the run says how many, and from which sequence.
This step can be GPU-intensive and may take several minutes. Keep the machine active during processing.

Output

Camera alignment data and sparse reconstruction saved to projects/<name>/rc_output/.

Troubleshooting

  • RC exits with error code — Check the Live Log for details; verify the .rscmd script path.
  • 0 cameras aligned — Too few overlapping frames; increase FPS in Step 2.
  • Slow alignment — Reduce frame count or upgrade GPU.
