Blender Post-processing (SplatForge)

Purpose

Run a headless Blender session with the SplatForge add-on to perform optional post-processing: cropping, scene composition, camera path baking, and final export to engine-ready formats.

What the script does

  1. Imports the .ply from export/.
  2. Applies configured transforms (scale, rotation, origin).
  3. Optionally crops to a bounding box.
  4. Exports to the target format (e.g. .glb, .splat).

Prerequisites

  • Blender ≥ 3.6 path configured in Settings.
  • SplatForge add-on installed in Blender.
  • Step 5 completed (valid PLY in export/).
This step is optional. If you only need a .splat or raw .ply file, you can stop after Step 5.
Blender's Python API is version-sensitive. Ensure your Blender version matches the SplatForge add-on requirements.

Output

Final processed scene saved to projects/<name>/export/.

Troubleshooting

  • Blender not found — Set the Blender executable path in Settings.
  • SplatForge import error — Re-install the add-on in Blender preferences.
  • Script fails silently — Check the Live Log for Python tracebacks.
