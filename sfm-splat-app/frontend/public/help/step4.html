LFS — Gaussian Splat Training

Purpose

Run Lichtfeld Studio (LFS) to train a 3D Gaussian Splatting model from the camera-aligned frames produced in Step 3. The result is a .ply file containing millions of coloured Gaussian primitives.

Key parameters

ParameterDefaultDescription
Iterations 30 000 Training steps — more = better quality but slower
Densification interval 100 How often to split/clone Gaussians
SH degree 3 Spherical harmonics degree (view-dependent colour)

How to use

  1. Confirm LFS path is set in Settings.
  2. Adjust iteration count if needed (30 k is the standard).
  3. Click Run Step 4.
  4. Watch the Live Log for per-iteration loss values.
A 30 000-iteration run on an RTX 3080 typically takes 10–20 minutes for ~200 frames.
Requires a CUDA-capable NVIDIA GPU. CPU training is not supported.

Output

Final point_cloud.ply and checkpoints saved to projects/<name>/lfs_output/.

Troubleshooting

  • CUDA out of memory — Reduce image resolution or frame count.
  • Loss diverges — Check camera alignment quality in Step 3.
  • LFS not found — Verify the Lichtfeld Studio path in Settings.
