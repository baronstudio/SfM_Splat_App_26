3DGS Pipeline App is a six-step desktop workflow that converts a video or image set into a polished 3D Gaussian Splatting scene, ready for web or engine import.

Pipeline overview

# Step Tool Output
1 Import Video / Images FFmpeg Raw frames in input/
2 Extract Frames FFmpeg Sampled frames in frames/
3 Reality Capture (RC) Reality Capture Aligned cameras + sparse cloud in rc_output/
4 LFS Training Lichtfeld Studio Gaussian splat .ply in lfs_output/
5 Export PLY SuperSplat Optimised .ply in export/

Quick start

  1. Click New Project in the top bar and give it a name.
  2. Follow the steps 1 → 6 in order; each step validates its prerequisites before running.
  3. Monitor progress in the Live Log panel at the bottom.
  4. Use Abort in the top bar to cancel a running pipeline safely.

Interface layout

  • Top bar — Project selector, step counter, Abort button.
  • Left sidebar — Step navigator; click any step to jump to it.
  • Center panel — Active step configuration and controls.
  • Right sidebar — Context-sensitive help (this panel).
  • Bottom panel — Live log output from the running pipeline.

Settings

Open Settings from the top bar to configure tool paths (FFmpeg, spirula) and pipeline defaults. Settings are persisted in config.json at the project root.

All tool paths must be valid before running any pipeline step.
