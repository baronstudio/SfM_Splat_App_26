Extract Frames

Purpose

Use FFmpeg to extract individual frames from the imported video at a controlled rate, saving them as JPEG images in frames/.

Parameters

ParameterDefaultDescription
FPS 2 Frames extracted per second of video
Quality 2 JPEG quality (1 = best, 31 = worst)
Max frames unlimited Optional hard cap on extracted frames

How to use

  1. Adjust FPS — higher = more frames = better coverage but slower RC.
  2. Leave Quality at 2 for photogrammetry (high quality JPEG).
  3. Click Run Step 2.
For a 60-second capture at 2 FPS you get ~120 frames — a good starting point. Aim for 80–300 frames for Reality Capture.
If the input is already an image set (not a video), this step copies images directly to frames/ without re-encoding.

Output

JPEG frames named frame_00001.jpg, frame_00002.jpg, … stored in projects/<name>/frames/.

Troubleshooting

  • FFmpeg not found — Verify the FFmpeg path in Settings.
  • 0 frames extracted — Check that the input video is not corrupt.
  • Blurry frames — Reduce FPS or use a tripod during capture.
