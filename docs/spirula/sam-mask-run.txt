### 3. Which naming does a reader pair by?  Both. 20 frames, identical numbers.
$ spirula --lang en sfm extract <20 frames> -o feat_nomask
[extract] done -- images: 20, features: 88230

$ spirula --lang en sfm extract <20 frames> -o feat_mask --masks <basename masks>
[extract] 20/20   frame_0020.jpg   Features: 5114   Masked out: 1443
[extract] done -- images: 20, features: 71301
[extract] masked out: 16929, over masked images: 20

$ spirula --lang en sfm extract <20 frames> -o feat_colmap --masks <".jpg.png" masks>

### 5. `train --mask-dir` DOES take an absolute path outside --data (§13.4)
# Three 200-iteration runs each way on the same 238-image dataset. The runs are
# not deterministic, but the two bands do not overlap: masked training treats the
# masked corners as empty space, which costs ~5 dB of psnr against an image that
# is not empty there.
#
#   --mask-dir <abs, 238 real masks> --apply-loss-for-mask 1
#       psnr 15.12   17.48   15.18      ssim 0.7947  0.8288  0.7631
#   --mask-dir <abs path that does not exist> --apply-loss-for-mask 1
#       psnr 22.40   22.68   20.33      ssim 0.8308  0.7850  0.7960
#
# NOTE the trap in the second row: a wrong --mask-dir exits 0 and trains
# unmasked. `--load-masks` is documented "use the dataset's masks when they
# exist", so a typo is silent -- which is why step 4 logs the mask count.
